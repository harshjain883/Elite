# Elitegram 12.10.1

Elitegram's first public release delivers an open-source Telegram client focused on privacy controls, customization, and power-user features.

## Highlights

- Advanced Ghost Mode and privacy controls
- Keep Deleted Messages for eligible locally received messages
- Up to 100 account slots with distinct Java/native mapping
- Selected Audio, Voice Effects, and device-audio call improvements
- Data-center information and the Elitegram Features hub
- Refined light and dark theme support
