# Telegram launch announcement

🚀 **Elitegram is now available!**

Elitegram is an open-source Telegram client for Android, built around practical privacy controls, customization, and power-user features.

✨ **Highlights**
• Advanced Ghost Mode and privacy controls
• Keep Deleted Messages for eligible messages
• Read, typing/recording, Seen on Reply, and story-view controls
• Voice Effects, Selected Audio, and device-audio improvements
• Up to 100 account slots
• Refined dark and light themes
• DC information and a dedicated Elitegram Features hub

🔓 **Open source**
The complete application source is public for transparency and independent inspection. Open source improves visibility into how the app works without making unrealistic security guarantees.
