# Privacy and transparency

Elitegram is an open-source Telegram client. Its source code can be inspected, built, and independently audited.

## Network communication

Elitegram communicates with Telegram infrastructure to provide Telegram account, messaging, media, story, and calling functionality. Builds configured with Firebase Cloud Messaging communicate with Google's Firebase services for push delivery. Android and device services selected by the user may also participate in platform features such as media selection, notifications, and calling.

The project website uses plain static HTML and CSS. It includes no analytics, tracking pixels, advertising scripts, or cookies.

## Local data

Telegram session and account data, downloaded media, preferences, and eligible Keep Deleted Messages archive data are stored locally by the Android application. Users should protect device access and use only official Elitegram downloads.

## Security scope

Open source improves transparency and makes independent review possible. It does not guarantee immunity from vulnerabilities, compromised devices, malicious repackaging, or third-party service risks. Report suspected vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
