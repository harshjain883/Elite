# Security policy

Please do not disclose a suspected vulnerability publicly before it can be reviewed.

Contact the maintainer through [@iflexsid on Telegram](https://t.me/iflexsid) with a concise description, affected version, reproduction steps, and impact. Do not include Telegram authentication codes, session material, private messages, signing keys, or other user credentials.

Official APKs are distributed through the [Elitegram GitHub Releases page](https://github.com/SkyBotsDeveloper/Elitegram/releases). Verify the SHA-256 value published with each release before installation.
