FEATURES

More control, without the clutter.

Ghost Mode

Fine-grained controls for presence, read status, typing, recording, and story activity.

Keep Deleted Messages

Locally retain eligible messages you already received while Telegram's normal deletion proceeds.

Up to 100 accounts

One-to-one Java and native account slots from 0 through 99, with the next account blocked at capacity.

Call tools

Selected Audio, Voice Effects, device-audio improvements, and No Mic Blink controls.

Useful details

Native themes

A polished interface designed to remain clear and readable in both light and dark modes.

PRIVACY & TRANSPARENCY

Inspectable by design.

Elitegram is open source, allowing its implementation to be inspected and independently audited. It communicates with Telegram infrastructure as a Telegram client and may use configured platform services such as Firebase for push delivery.

Open source improves transparency; it is not a guarantee against vulnerabilities. Download only from official Elitegram links.

OPEN SOURCE

The real implementation.

The public repository contains the Java, native C/C++, resources, build configuration, and feature implementation required to inspect and build Elitegram. Private signing credentials and runtime account data are never part of the source distribution.
